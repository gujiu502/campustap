CampusTap 0.7.2：处理明确停用、尚无身份记录的欧加初始状态。

用户提供的一加 CPH2653 / Android 16 / CPH2653_16.0.10.501(EX01) 报告确认：欧加接口与功能检测通过，四项身份记录为空，没有待恢复资料。旧报告只给出 MODE 格式有效，没有显示0或1，因此尚不能断定该机处于停用模式。

- 新增严格分支：只有 MODE 明确为0，且 ATQA、SAK、UID、UID getter 全空时，按“无已配置身份的停用状态”处理；不以编造的卡号填充备份。
- 仍先加密保存状态与准备写入标记，再调用厂商 setter。MODE不明、MODE为1、部分记录缺失或格式异常时继续停止。
- 从此初始状态恢复时，使用已公开分析的厂商停用调用参数，并检查覆盖已停用且状态为空或为预期停用标记。可能留下系统新生成的停用记录，不声称恢复最初不存在的设置键或完整RF配置。
- 停用状态下 UID getter 可为空；启用成功仍必须读到完整且匹配的目标参数与 UID，不将空回读视为成功。
- 兼容性信息新增实际模式与空停用状态标志；报告当前选择的后端候选，避免把“若有ST权限时的优先接口”误认为实际控制器。未添加型号白名单。

Debug／Release各62项 JVM 测试通过，lint 0 errors / 16 warnings。新增8项覆盖初始状态识别、拒绝活动／部分空状态、初始化前备份、失败停用、外部卡片保护、错误恢复回读及恢复重试。沿用旧签名，覆盖安装保留卡片。

**这是有条件的实验性修复，目标手机的实际设置、停用恢复和刷门禁仍未验证。** 如果MODE并非0或厂商调用被拒，本版仍无法启用。不改付款钱包，不依赖无线调试或Root。
