CampusTap 0.7.0：一加／OPPO／Realme 实验性直接接口后端。

本版已加入实际设置与恢复代码，不再只检测接口。此路径不需要无线调试或辅助 App，也不先要求授予 ST 后端所需的系统设置权限；厂商服务本身仍可能拒绝调用。

- 直接调用系统提供的有类型 NFC 接口，不猜 Binder 编号、不绕过隐藏 API、不改默认付款钱包。
- 启用须通过功能开关、完整可读取的停用状态及一致性检查。原状态缺失、编码未知或存在活动卡时拒绝写入。
- 加密保存并核对恢复资料，在设置前持久化准备写入标记；失败自动尝试恢复。其他操作改变卡片时不覆盖其身份，恢复失败保留资料。
- 回读只证明厂商状态一致，不代表实际控制器或开门成功。恢复只核对厂商元数据与停用操作，不声称完整 RF 配置逐字节恢复。
- 默认卡、点击切换、暂停、NFC 开关后的自动启用均接入后端选择；已有授权 ST 仍优先使用原实现。

**没有目标手机实测，不能保证一加或 Realme GT Neo 2 已能刷门禁。** 某些 ROM 未提供状态键或接口时，本版仍会停止。适用范围与依据见 [兼容性说明](https://github.com/gujiu502/campustap/blob/master/docs/vendor-compatibility.md)。
