CampusTap 0.6.3 修复授权页面把软件锁住的问题，清理普通界面的技术说明。

- 删除长授权弹窗、ADB命令、复制命令和误导的“前往授权”按钮。
- 基本 NFC 已授权即可进入卡片列表、编辑与读卡；系统特权缺失不再把整个软件锁住。
- 实际启用卡片模拟仍检查厂商接口适配与系统授权；不伪造授权成功，也不以读卡成功代替模拟成功。
- 系统不可直接授予的权限、未适配设备仅显示简短状态。NFC设置按钮只打开真实的系统 NFC 设置。

本版是界面与阻塞流程修复，**没有新增 Realme GT Neo 2（RMX3370）的门禁模拟支持**。用户当前无法接机，NFC接口适配留待设备核验。Android的基本 NFC 为安装时普通权限，WRITE_SECURE_SETTINGS 是另一项系统特权，不能用普通运行时权限弹窗授予。[Android官方权限文档](https://developer.android.com/reference/android/Manifest.permission#WRITE_SECURE_SETTINGS)

Debug／Release各21项测试通过，lint均0 errors / 16 warnings；编译后入口只检查基本 NFC，实际模拟权限与设备检查保留；长弹窗与命令已从普通UI移除。Release不可调试、无debug探针，沿用已有测试签名，覆盖安装保留卡片资料；不要先卸载或清除数据。当前版本尚未真机复测。
